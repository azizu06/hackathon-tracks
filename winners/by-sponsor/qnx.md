## 2026 winners

### [Combadge](https://devpost.com/software/combadge)

[Hack the North 2026](../by-hackathon/hack-the-north-2026.md#project-combadge) · **Create an Embedded System with QNX that Uses AI**

Inspired by Star Trek’s combadge and ship’s computer: a wearable AI communicator combining voice, vision, and actions. Just say, “Computer.”.

**How it used QNX:** The Pi runs QNX 8.0 and connects to a microphone, speaker, and camera.

[Demo video](https://www.youtube.com/watch?v=ZbD7XTCFx-I) · Built with qnx, bluetooth, browserbase, btstack

### [EyeMelody](https://devpost.com/software/dual-vision-glasses)

[Hack the North 2026](../by-hackathon/hack-the-north-2026.md#project-dual-vision-glasses) · **Create an Embedded System with QNX that Uses AI**

The team've built a headset where one camera watches your eye, one watches the table in front of you.

**How it used QNX:** The team built a head-mounted eye-tracking instrument on a Raspberry Pi 5 running QNX 8.0.

[Code](https://github.com/pravoslavzilka/htn-gaze) · [Demo video](https://www.youtube.com/watch?v=8T5pSdE79tU) · Built with elevenlabs, huawei-omni, node.js, numpy

### [MOGGIE](https://devpost.com/software/moggie)

[UC Berkeley AI Hackathon 2026](../by-hackathon/uc-berkeley-ai-hackathon-2026.md#project-moggie) · **Best Use of QNX**

QNX-powered, computer-vision-driven viral arcade system. Compete in instant 1v1 battles from online trends like six-seven and mogging.

**How it used QNX:** The team got a real Raspberry Pi Camera Module 3 feed running inside a Pygame game on QNX, a use case in uncharted territory for QNX.

[Code](https://github.com/BeanyZoldyck/moggie) · [Demo video](https://www.youtube.com/watch?v=YuO-1lJqAFQ) · Built with qnx, mediapipe, opencv, pika

### [SafeTank](https://devpost.com/software/safetank)

[UC Berkeley AI Hackathon 2026](../by-hackathon/uc-berkeley-ai-hackathon-2026.md#project-safetank) · **Best Use of QNX**

Real-time monitoring and AI-powered predictive maintenance for factory plants.

**How it used QNX:** A key part of the system is QNX RTOS, an industry-grade real-time operating system commonly used in safety-critical and industrial applications.

Built with c++, python

### [SpideyIRL](https://devpost.com/software/sixth-sense-pk24ul)

[Hack the North 2026](../by-hackathon/hack-the-north-2026.md#project-sixth-sense-pk24ul) · **Create an Embedded System with QNX that Uses AI**

SpideyIRL is built around one core idea: &#42;reflexes should never have to wait for intelligence. &#42;.

**How it used QNX:** One targets QNX for the low level sensing and haptic loop, while the second runs Linux for computer vision, speech, and the multimodal assistant.

[Code](https://github.com/adi-padmarajan/SpideyIRL) · [Demo video](https://www.youtube.com/watch?v=9_8m-XiTdOw) · Built with qnx-neutrino-rtos, c, gpio, haptics

### [QNX-RasPi-Setup-Util](https://devpost.com/software/qnx-raspi-setup-util)
