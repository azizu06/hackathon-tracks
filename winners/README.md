# Winners index

Browse 178 projects across 16 hackathon editions. The index has 187 awards across 27 sponsors.

[CSV](winners.csv) · [JSON](winners.json) · [Track-first method](../README.md)

Each row is one project and prize. Sponsor pages summarize patterns in the examples listed there. The Built With column shows relevant tags from the project page. A missing tag means the page lacks a matching entry in that section. For product and theme challenges, the column can include hardware, models, or other implementation tech relevant to the track.

Devpost marks the awards in the index as winners, with one sponsor-reported prize for Backrooms. Its Devpost page supplies the project details and the Cal Hacks gallery supplies the Hyphenate track name.
